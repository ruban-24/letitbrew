# Let It Brew Trademark Policy

Last updated: 17 August 2026

## Owner and official project

Ruban claims rights in the Let It Brew name, the flask logo, and the Violet
Signal app icon and visual identity. The official project is
https://github.com/ruban-24/letitbrew and the official site is
https://letitbrew.app.

## Relationship to the software license

The source code for v0.6.0 and later is licensed under Apache License 2.0.
That license permits commercial use, modification, and redistribution of the
code, but Section 6 does not grant rights to use Let It Brew trademarks except
for reasonable and customary description of the work's origin. This policy
governs the marks, not the code.

## Uses that do not require permission

- Truthfully referring to the official, unmodified Let It Brew project.
- Linking to the official repository or site.
- Making accurate compatibility statements such as "works with Let It Brew"
  when they do not imply sponsorship or endorsement.
- Identifying a fork as derived from Let It Brew in documentation or notices,
  provided the fork itself uses a distinct product name and branding.
- Editorial, educational, and other uses permitted by applicable law.

## Uses that require written permission

- Distributing a modified build under the Let It Brew name, flask logo, Violet
  Signal icon, or confusingly similar branding.
- Using the marks in an app name, repository name, package name, domain, social
  account, paid service, merchandise, advertising, or event branding in a way
  that could imply an official source, sponsorship, or endorsement.
- Registering or attempting to register confusingly similar marks or account,
  package, domain, or app-store identifiers.

## Forks and redistributed builds

A redistributed modified build must use a distinct name and icon, change the
bundle identifiers and signing-team assumptions described in CONTRIBUTING.md,
and state clearly that it is an independent fork. Apache attribution and NOTICE
requirements still apply. These naming requirements do not prohibit charging
for or commercially supporting code used in accordance with Apache 2.0.

## Permission requests and enforcement

Request permission through Ruban's official GitHub profile at
https://github.com/ruban-24. Permission must be in writing. Ruban may request
that confusing use of the marks stop. Nothing in this policy limits rights that
applicable law grants without permission.
